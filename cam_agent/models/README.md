# cam_agent/models/

This directory contains the ML model files used by the inference agent.

## Files

### `yolov8n-pose.pt`
YOLOv8 nano pose-estimation model from Ultralytics.
Used to detect the 17-keypoint COCO skeleton from each camera frame.

If missing, download from:
```
https://github.com/ultralytics/assets/releases/download/v8.1.0/yolov8n-pose.pt
```
Place it at `cam_agent/models/yolov8n-pose.pt`.

#### ONNX export (recommended for faster startup)

Exporting to ONNX skips PyTorch graph construction and runs via ONNX Runtime —
around **60% faster load time and inference** on CPU with no accuracy loss.

Run once after placing `yolov8n-pose.pt`:
```bash
cd cam_agent
python training/export_onnx.py
# → models/yolov8n-pose.onnx
```

Then update `config/config.yaml`:
```yaml
pose_model_path: "models/yolov8n-pose.onnx"
```

If `yolov8n-pose.onnx` is absent, `inference_agent.py` falls back to `.pt` automatically
(Ultralytics `YOLO()` is transparent to format — no code change needed).

### `drowsiness_mlp.pkl`
Trained drowsiness classifier (RandomForest pipeline with StandardScaler).
Input: 35-dimensional feature vector — normalized COCO keypoints (nose-centered,
scaled by inter-eye distance) concatenated with EAR (Eye Aspect Ratio).

**Achieved accuracy: 98% F1 on held-out test set.**

Generated by running:
```bash
cd cam_agent/training
python train.py --augment
```
See `docs/DATASET_GUIDE.md` for dataset preparation instructions.

## Fallback behaviour
If `drowsiness_mlp.pkl` is missing the agent operates in **EAR-only mode**
(threshold-based drowsiness detection without the ML classifier).
